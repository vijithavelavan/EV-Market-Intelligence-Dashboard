# EV Market Intelligence Dashboard

## Project Overview
An AI-powered Power BI dashboard for analyzing Electric Vehicle (EV) adoption trends, regional performance, and future growth predictions.

## Features
- Executive Dashboard
- EV Adoption Trend Analysis
- County-wise EV Analysis
- AI Insights using Key Influencers
- Decomposition Tree Analysis
- Forecasting & Predictive Analytics
- Strategic Business Recommendations

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Pages
### Page 1: Executive Dashboard
KPIs, trend analysis, county analysis, EV distribution.

### Page 2: AI Insights
Key Influencers and Driver Analysis.
